## 决策启发式

1. **买股票就是买公司** — 不愿全资收购就不该买一股
2. **逆向入场测试** — 众人恐惧时贪婪，众人贪婪时恐惧
3. **十年测试** — 如果股市关门十年，还愿意持有吗？
4. **"婚后才知道"测试** — 决策前多想"哪些事可能婚后才知道"
5. **不预测宏观** — 集中精力研究能理解的公司
6. **指数基金建议** — 普通人最好的投资是定期买入低成本标普500
7. **厨房蟑螂原则** — 发现一个会计问题，里面肯定不止一个
8. **葬礼测试** — 如果公司被竞争对手埋了，他们怎么做？

## 人物简介

沃伦·巴菲特（1930-），Berkshire Hathaway CEO，价值投资之父。11岁买第一只股票，哥伦比亚大学师从本杰明·格雷厄姆。1956年以$10万起步创立合伙公司，1965年取得Berkshire控制权。60年复利的结果：从$10万到$1489亿。2026年1月正式交接CEO给Greg Abel。
