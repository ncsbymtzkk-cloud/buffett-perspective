## 一、重大投资决策（成功案例）

### 1.1 Coca-Cola（1988年开始买入）

| 维度 | 内容 |
|------|------|
| **时间** | 1988年 |
| **规模** | 10.2亿美元买入可口可乐7%股份 |
| **事实** | 巴菲特从1988年开始重仓买入可口可乐，最终持有约7%股份。该投资成为伯克希尔最赚钱的投资之一，至今仍在持有。截至2025年底，伯克希尔持有9.3%股份，市值约318亿美元。 |
| **决策背景** | 1987年股灾后可口可乐股价回落。1980年代可口可乐在CEO Roberto Goizueta领导下进行重大转型：推出健怡可乐、全球化扩张、资产轻量化。 |
| **决策逻辑（事实）** | 巴菲特看重可口可乐的品牌护城河（全球最强消费品牌之一）、定价权（消费者对价格不敏感）、轻资产高回报的商业模式、全球化增长空间。这些特征完全符合他"经济护城河"投资框架。 |
| **决策逻辑（推断）** | 可口可乐是巴菲特从"烟蒂股"转向"优质企业"投资哲学的典型代表。早期的他会等可口可乐被低估时买入，但1988年的买入更多是看清了其品牌壁垒和全球扩张潜力，愿意为优质企业支付合理价格。 |
| **结果** | 到2025年底市值约318亿美元，年化回报远超同期标普500。持续分红为伯克希尔带来稳定现金流。 |
| **来源** | Wikipedia: Warren Buffett, Wikipedia: Berkshire Hathaway — 可信度: High |

### 1.2 GEICO（1976年初投，1996年全资收购）

| 维度 | 内容 |
|------|------|
| **时间** | 1951年首次买入（个人账户）；1976年伯克希尔大举买入；1996年全资收购剩余49% |
| **关键事实** | 巴菲特的GEICO情结始于1951年。他得知本杰明·格雷厄姆是GEICO董事会成员后，专程前往华盛顿拜访副总裁Lorimer Davidson，讨论了数小时的保险业务。这次会面让Davidson成为他的终生朋友和导师。1976年当GEICO面临财务困难、股价极低时，伯克希尔开始大举买入。1996年以23亿美元收购剩余49%股份。 |
| **决策逻辑（事实）** | 低成本的直接销售模式（没有中介佣金）构成可持续的竞争优势；保险浮存金（float）为投资提供低成本杠杆资金；公司管理层在危机中有能力扭转局面。 |
| **决策逻辑（推断）** | GEICO是巴菲特"在别人恐惧时贪婪"原则的早期体现。1976年GEICO濒临破产时巴菲特下重注，显示出他对保险行业和公司商业模式有极深的理解，敢于在公司最困难时逆势买入。这与他后来在2008年金融危机中的操作一脉相承。 |
| **结果** | GEICO成为伯克希尔核心利润来源和最大的汽车保险公司之一。浮存金机制为伯克希尔的投资提供了源源不断的低成本资金。 |
| **来源** | Wikipedia: Warren Buffett — 可信度: High |

### 1.3 American Express（1964年"色拉油丑闻"后买入）

| 维度 | 内容 |
|------|------|
| **时间** | 1964年初次买入；后续数十年持续增持 |
| **规模** | 截至最新数据，伯克希尔持有American Express约22.1%股份，市值约522亿美元 |
| **决策背景** | 1963年American Express因"色拉油丑闻"（一家子公司被欺诈，涉及伪造色拉油库存作为抵押品）股价暴跌近50%。市场恐慌认为公司可能面临巨额赔偿。 |
| **决策逻辑（事实）** | 巴菲特冷静分析了丑闻的性质：虽然子公司被欺诈，但核心的旅行支票和信用卡业务并未受损，品牌信任度和用户粘性没有实质损害。丑闻是一次性事件，不影响长期竞争力和盈利能力。这次投资体现了他"识别暂时性危机 vs. 永久性损害"的区分能力。 |
| **决策逻辑（推断）** | 巴菲特看到了市场对美国运通的过度反应。他判断旅行支票和信用卡的"生态系统效应"（商家越多人用、用户越多商户收）构成强大的网络效应护城河，竞争对手难以复制。 |
| **结果** | 持续持有超过60年，成为伯克希尔最成功的长期投资之一。 |
| **来源** | Wikipedia: Berkshire Hathaway — 可信度: High |

### 1.4 Apple（2016年开始买入）

| 维度 | 内容 |
|------|------|
| **时间** | 2016年Q1首次买入980万股（~10亿美元）；到2022年底持有5.8%股份；2024年Q2减持约50%（卖出755亿美元） |
| **关键事实** | 当伯克希尔首次买入Apple时，市场震惊——因为巴菲特口口声声说"不投科技股"。但实际上这笔买入是由巴菲特的投资副手Ted Weschler或Todd Combs之一主导的。 |
| **决策逻辑（事实）** | 巴菲特将Apple定义为"消费品公司"而非"科技公司"。他的逻辑是：iPhone拥有极强的品牌忠诚度（"定价权"），用户对价格不敏感且很难转投安卓阵营，形成类似可口可乐的"经济护城河"。Apple的生态系统（App Store、iCloud、硬件锁定）创造高用户转换成本。 |
| **决策逻辑（推断）** | 这里有一个关键转折：巴菲特早期确实不理解科技公司，但到2016年iPhone已经成为全球最普及的消费品之一，他自己也用iPhone。他看Apple的逻辑与看可口可乐完全一致——不是看技术好坏，而是看品牌粘性、定价权和用户锁定。这并非他改变了"不投科技股"的原则，而是他重新定义了Apple——不在"科技公司"分类里，而在"必需消费品"分类里。这与芒格的"反过来想"方法一致：不要问"这是不是科技股"，要问"这公司有没有护城河"。 |
| **结果** | 到2024年减持前，Apple成为伯克希尔最大持仓（一度占投资组合的50%左右），为伯克希尔带来数千亿美元收益。2024年大幅减持可能是出于组合管理、税收考虑或对估值的判断。 |
| **来源** | Wikipedia: Berkshire Hathaway — 可信度: High |

### 1.5 See's Candies（1972年收购——芒格说服他）

| 维度 | 内容 |
|------|------|
| **时间** | 1972年 |
| **规模** | 2500万美元收购 |
| **关键事实** | 这是巴菲特投资哲学转型的里程碑事件。芒格说服巴菲特从"烟蒂股"投资法转向"合理价格买入优质企业"。See's Candies具有定价权、品牌忠诚度、轻资产高回报等特征。到2019年，这笔投资累计回报超过20亿美元——8000%的回报率。 |
| **决策逻辑（事实）** | 巴菲特后来称See's Candies是他"梦想中的企业"：可预测的收入（每年50%收入来自11月-12月的节假日季）、强大的品牌认知、几乎无需资本再投入、拥有定价权。 |
| **决策逻辑（推断）** | 这笔交易的价值不在See's本身赚了多少钱（相对于伯克希尔整体是个小数字），而在于它彻底改变了巴菲特的投资框架。如果没有See's的经验，他可能永远不会买入可口可乐、GEICO等优质企业。芒格在这笔交易中扮演了关键角色——他是那个推动巴菲特从"格雷厄姆体系"向"费雪/芒格体系"进化的人。 |
| **结果** | 到2019年累计回报超过20亿美元。更重要的是，这笔投资重塑了巴菲特的投资哲学。 |
| **来源** | Wikipedia: Berkshire Hathaway — 可信度: High |

### 1.6 Washington Post（1973年买入）

| 维度 | 内容 |
|------|------|
| **时间** | 1973年开始买入；2014年退出（交换为电视台资产） |
| **关键事实** | 巴菲特与华盛顿邮报控股股东Katharine Graham建立了深厚的友谊，并加入了董事会。这笔投资既是商业决策也是人脉投资。最初投资约1060万美元。 |
| **决策逻辑（事实）** | 巴菲特看重华盛顿邮报在华盛顿特区的垄断地位——当时美国主流报纸拥有极强的地区性护城河（"唯一报纸城市"效应）。华盛顿邮报作为首都主导报纸，拥有不可复制的内容壁垒。 |
| **决策逻辑（推断）** | 这笔投资也是巴菲特对"无形资产"认识的早期案例——报纸的品牌、政府关系网络、订阅基础构成强大的进入壁垒。虽然这一逻辑在互联网时代崩溃了，但在1970年代是完全合理的。 |
| **结果** | 巴菲特于2014年将大部分华盛顿邮报股份交换为WPLG-TV电视台资产。持有期超过40年，回报丰厚。 |
| **来源** | Wikipedia: Washington Post Company — 可信度: Medium（条目中未包含完整细节） |

### 1.7 Burlington Northern Santa Fe铁路（2009年全资收购）

| 维度 | 内容 |
|------|------|
| **时间** | 2007年买入10.9%（3.23亿美元）；2009年宣布全资收购；2010年完成 |
| **规模** | 340亿美元（现金+股票）；含100亿美元债务承担后约440亿美元 |
| **关键事实** | 当时是伯克希尔历史上最大收购。伯克希尔传记作者Alice Schroeder指出一个重要动机：将伯克希尔从金融行业（保险）多元化到实体经济。 |
| **决策逻辑（事实）** | 巴菲特押注美国经济的长期增长——铁路运输是美国货运的骨架，BNSF占据西部铁路网络的战略位置。铁路运输具有极高的进入壁垒（土地、轨道、监管），且燃油效率高。BNSF有稳定的定价权和持续的现金流。 |
| **决策逻辑（推断）** | 这笔交易体现了巴菲特对"后金融危机时代"的判断：2008年金融危机后，他大量减少金融行业敞口，转向基础设施和实体经济。BNSF不仅是价值投资，更是一种"国家基础设施垄断"的配置。同时铁路受益于油价上涨（铁路比卡车更省油），有对冲通胀的功能。 |
| **结果** | BNSF成为伯克希尔最稳定的利润来源之一，年利润持续贡献数十亿美元。 |
| **来源** | Wikipedia: Warren Buffett, Wikipedia: Berkshire Hathaway — 可信度: High |

## 二、重大投资错误

### 2.1 Berkshire Hathaway本身（纺织厂）

| 维度 | 内容 |
|------|------|
| **时间** | 1965年买入控制权 |
| **关键事实** | 巴菲特公开承认这是他"最大的投资错误"。他估计这笔错误在45年间让他损失了约2000亿美元的复利回报。 |
| **决策逻辑（推断）** | 这次买入完全是情绪化决策——公司CEO原本报价11.50美元/股回购巴菲特的股份，但实际执行时只出了11.375美元/股。巴菲特感到被欺骗，愤怒之下大量买入并夺得了公司控制权。这是巴菲特职业生涯中最著名的"报复性投资"错误，完全违背了他自己"理性决策"的原则。 |
| **教训** | 永远不要让情绪驱动投资决策；劣质企业不会因为买得便宜就变成好企业。 |
| **来源** | Wikipedia: Warren Buffett, Wikipedia: Berkshire Hathaway — 可信度: High |

### 2.2 Dexter Shoes（用股票收购的灾难性错误）

| 维度 | 内容 |
|------|------|
| **时间** | 1993年 |
| **关键事实** | 巴菲特以伯克希尔股票（25203股A类股）收购Dexter Shoes，当时价值约4.33亿美元。这些股票后来价值增长到数十亿甚至上百亿美元。Dexter Shoes本身业务随后崩溃，价值归零。 |
| **决策逻辑（推断）** | 巴菲特犯了两个错误：第一，没有意识到Dexter的竞争优势（低成本制鞋）不可持续——美国制鞋业无法与亚洲低成本进口竞争；第二，也是最致命的——用伯克希尔股票支付，等于用未来的复利为错误买单。巴菲特后来在致股东信中痛陈："用股票收购公司就像用家传珍宝换垃圾。" |
| **结果** | 这是巴菲特眼中代价最大的错误（按机会成本计算），因为损失的不仅是收购款，还有错失的伯克希尔股票未来巨大增值。 |
| **来源** | 注：Wikipedia条目未包含具体细节，数据来自巴菲特历次致股东信。可信度: High（广泛引用的已知事实） |

### 2.4 航空股（2020年疫情中清仓）

| 维度 | 内容 |
|------|------|
| **时间** | 2016年-2020年（持有）；2020年4月清仓 |
| **关键事实** | 巴菲特数十年间多次称航空业是"投资者的死亡陷阱"（deathtrap for investors），但在2016-2017年间成为美国四大航空公司（美国航空、达美、西南、联合）的最大股东之一。2020年4月，他在疫情中卖出了所有航空股。 |
| **决策逻辑（推断）** | 买入侧：巴菲特可能认为经过多年整合，美国航空业从割据竞争变成寡头垄断，定价能力改善。卖出侧：疫情让航空旅行几乎归零，他判断航空业的商业模式无法承受长期需求冻结——固定成本高企、债务剧增。这与他在1989年US Airways优先股投资的"死里逃生"经验一致。 |
| **关于"卖早了"的说法** | 这是一个存在争议的推断。2020-2022年间航空股从底部大幅反弹，有观察者认为巴菲特卖在了底部。但巴菲特本人从未公开表达过后悔卖早——他更可能认为在不确定时期"保本第一"。 | 
| **来源** | Wikipedia: Berkshire Hathaway — 可信度: Medium（具体推理过程是推断） |

### 2.5 Kraft Heinz（与3G Capital的合作后遗症）

| 维度 | 内容 |
|------|------|
| **时间** | 2013年与3G联合收购亨氏（280亿美元含债务）；2015年与卡夫合并 |
| **规模** | 伯克希尔投入了大量资本 |
| **关键事实** | 2019年巴菲特承认"收购价过高"（overpaid）。卡夫亨氏遭遇了多重问题：品牌老化、零售渠道变化（自有品牌崛起）、3G的激进成本削减损害了品牌和产品品质。 |
| **决策逻辑（推断）** | 巴菲特在选择合作伙伴上犯了错。3G Capital的零基预算（zero-based budgeting）文化以极端成本削减著称，这与巴菲特通常让被收购企业自主经营的风格相冲突。巴菲特可能高估了卡夫亨氏品牌护城河（低估了零售商自有品牌的冲击），也低估了3G激进削减成本对品牌价值的长期损害。 |
| **来源** | Wikipedia: Berkshire Hathaway, Wikipedia: 3G Capital — 可信度: High（事实部分） |

### 2.6 IBM（2011年买入，2018年前后清仓）

| 维度 | 内容 |
|------|------|
| **时间** | 2011-2018年 |
| **规模** | 约110亿美元买入5.5%股份（6400万股） |
| **关键事实** | 2011年巴菲特买入IBM令市场震惊——他一直说"不投科技股"。到2018年，伯克希尔清空了全部IBM仓位。 |
| **决策逻辑（推断）** | 巴菲特买入IBM的逻辑：IBM拥有大型企业客户粘性（转换成本高）、稳定的IT服务收入、股票回购缩减股本。但他低估了云计算对IBM传统IT服务模式的颠覆——Amazon AWS、Microsoft Azure等云服务商正在快速侵蚀IBM的核心业务。IBM的收入增长停滞，转型缓慢。这笔投资失败说明巴菲特的"护城河"分析框架在面临技术范式转换时可能失效——他认为的"客户粘性"在技术更替面前是不牢固的。 |
| **结果** | 公开资料未披露具体亏损额，但这是一次明确的清仓出局。 |
| **来源** | Wikipedia: Berkshire Hathaway — 可信度: High |

### 2.8 康菲石油（ConocoPhillips，2008年高点买入）

| 维度 | 内容 |
|------|------|
| **时间** | 2008年（卖出在2009年） |
| **关键事实** | 巴菲特在石油价格接近历史高点时大量买入康菲石油股份至8500万股，随后油价在金融危机中暴跌。他公开称这是"重大错误"（a major mistake）。 |
| **决策逻辑（推断）** | 这是一个典型的"追涨"错误。2008年油价飙升时，巴菲特可能被通胀逻辑吸引——认为石油将长期供不应求。但他没有预料到金融危机导致全球需求崩溃。这证明即使是巴菲特也无法预测大宗商品价格走势。 |
| **来源** | Wikipedia: Warren Buffett, Wikipedia: Berkshire Hathaway — 可信度: High |

## 三、非投资决策

### 3.1 捐赠承诺（Giving Pledge）

| 维度 | 内容 |
|------|------|
| **关键事实** | 2010年，巴菲特与比尔·盖茨和梅琳达·盖茨共同创立了"捐赠誓言"（The Giving Pledge），承诺将绝大部分财富捐给慈善事业。他个人累计承诺捐赠超过600亿美元。 |
| **后续变化** | 盖茨离婚后，巴菲特与盖茨基金会"变得疏远"，转而向其三个孩子的慈善基金会各捐赠5亿美元。 |
| **决策逻辑（推断）** | 巴菲特的捐赠哲学有两个独特之处：一是他坚持"在世捐赠"而不是留到去世后；二是他对慈善的参与度较低——不像盖茨亲力亲为，巴菲特选择"把钱交给会花的人"。这与他作为投资者的风格一致：找到信任的人，然后放手。 |
| **来源** | Wikipedia: The Giving Pledge — 可信度: High |

### 3.2 继任计划（Greg Abel接任）

| 维度 | 内容 |
|------|------|
| **关键事实** | 2021年5月，巴菲特首次公开确认Greg Abel为继任者。2025年5月股东大会上宣布Abel在年底接任CEO。2026年1月，Abel正式成为伯克希尔哈撒韦的总裁兼CEO。 |
| **选择Abel而非Ajit Jain的原因** | Abel在2008年起执掌中美能源（后更名为伯克希尔能源），2018年被任命为非保险业务副董事长。媒体报道将他的胜出归因于"强烈的职业道德和战略思维"以及对价值投资的承诺。 |
| **决策逻辑（推断）** | 选择Abel而不是Ajit Jain的关键区别：Abel管理的是非保险业务（能源、铁路、公用事业等），这些是伯克希尔最大的重资产板块；Jain主管保险业务，虽然同样出色但保险业务已高度成熟。另一个可能原因：Abel长于资本配置和大型交易（更接近巴菲特的角色），而Jain是运营天才但未必适合CEO角色。 |
| **来源** | Wikipedia: Greg Abel, Wikipedia: Berkshire Hathaway — 可信度: High |

### 3.3 政治立场和捐款

| 维度 | 内容 |
|------|------|
| **关键事实** | 巴菲特是民主党支持者，多次公开支持提高富人税收。2011年在《纽约时报》发表专栏"停止宠坏超级富豪"（Stop Coddling the Super-Rich），提出富人税率不应低于中产阶级。奥巴马政府据此提出了"巴菲特规则"（Buffett Rule），要求年收入百万美元以上的家庭最低有效税率不低于30%。 |
| **与芒格的区别** | 芒格在政治立场上比巴菲特保守（虽然也自称民主党人），芒格更倾向于自由放任资本主义，对政府干预持更多怀疑态度。两人在税收、监管等问题上的公开表述有明显温差。 |
| **来源** | Wikipedia: Buffett Rule — 可信度: High |

### 3.4 反收购激进投资者（与3G Capital的关系处理）

| 维度 | 内容 |
|------|------|
| **关键事实** | 巴菲特与3G Capital合作收购亨氏（2013年）并合并卡夫（2015年）。3G Capital以零基预算和极端成本削减闻名。 |
| **决策逻辑（推断）** | 巴菲特与3G的合作反映了他对自己能力圈的清醒认识——食品行业的运营优化不是他的强项，所以他引入3G来管理运营端，自己管资本端。但后来的事实证明：3G的过度成本削减损害了品牌长期价值（产品品质下降、人才流失）。巴菲特在2019年承认对卡夫亨氏的收购价过高，虽未直接批评3G，但隐含了对合作关系的高估。这件事后，巴菲特再也没有与激进投资者进行过类似的大型合作收购。 |
| **来源** | Wikipedia: 3G Capital, Wikipedia: Berkshire Hathaway — 可信度: High（事实部分） |

## 四、投资原则如何落地

### 4.1 "不投科技股"却买入Apple——决策逻辑是什么？

| 维度 | 内容 |
|------|------|
| **事实** | 巴菲特公开称Apple是"消费品公司"而非"科技公司"。他不再使用"科技"这个分类标签来定义Apple。 |
| **核心逻辑（推断）** | 这里需要区分巴菲特的"能力圈边界"和他的"分类方式"。他的能力圈边界并无实质变化——他仍然不投那些他不理解技术模式的公司。但是Apple被他重新"分类"：一个拥有极致用户忠诚度、强大生态锁定效应、极高客户终身价值的消费品品牌。在这一点上，Apple和可口可乐、吉列并没有本质区别。 |
| **关键转折** | 实际上首次买入Apple的决策可能并非巴菲特本人——是他的投资副手Ted Weschler或Todd Combs之一推荐并主导的。但巴菲特在深入了解后，对Apple的逻辑完全认同。 |
| **与IBM的对比** | IBM也是科技股，同样以"客户粘性"为买入逻辑。为什么IBM失败而Apple成功？因为IBM的"客户粘性"是企业IT服务习惯，可以被云计算颠覆；而Apple的"用户粘性"是个人消费者生态锁定（App + 硬件 + 数据迁移成本），技术代际更迭不直接破坏这种粘性。但这是事后的角度——事前区分这两者并不容易，巴菲特在IBM上的失败可能恰恰让他更清楚地看到了Apple护城河的真正本质。 |
| **来源** | Wikipedia: Berkshire Hathaway — 可信度: High（事实）/ Medium（推断） |

### 4.2 他说"不投航空股"——后来改变了吗？

| 维度 | 内容 |
|------|------|
| **事实** | 巴菲特在1989年投资US Airways优先股，几乎血本无归（后来说这是他"差点死掉"的经历），从此称航空业是"投资者的死亡陷阱"。但2016-2017年他大举买入美国四大航空股。2020年4月清仓全部航空股。 |
| **决策逻辑变化（推断）** | 买入逻辑：经过多年的行业整合（兼并重组），美国航空业从碎片化竞争变成了四大寡头垄断。巴菲特可能认为定价能力改善了、产能纪律增强了。卖出逻辑：疫情导致航空需求冻结到几乎为零，固定成本极高（飞机租赁、燃油、人力），债务累积不可持续。 |
| **最终结论** | 巴菲特看似"改变了对航空股的看法"，但实际上他只是在不同的市场环境下做了不同的判断。他的核心原则没变——看行业结构和竞争格局。当他认为结构改善时买入，当结构崩溃时卖出。但2020年的清仓也说明，这次"改变想法"的投资并没有好的结局（虽然无法证实他是否后悔）。 |
| **来源** | Wikipedia: Berkshire Hathaway — 可信度: Medium（推断成分较大） |

### 4.3 2008年金融危机中的决策（高盛优先股）

| 维度 | 内容 |
|------|------|
| **时间** | 2008年9月（金融危机最恐慌时刻） |
| **规模** | 50亿美元高盛优先股 + 认股权证 |
| **关键事实** | 2008年9月，雷曼兄弟刚刚破产，AIG被国有化，市场陷入极度恐慌。巴菲特以50亿美元买入高盛优先股，年息10%（每年5亿美元股息），同时获得以115美元/股认购高盛4350万股普通股的权证。 |
| **交易条款** | 优先股年化10%收益率；高盛可溢价10%赎回（即55亿美元）；权证5年有效期，行权价115美元/股。 |
| **结果** | 2011年3月高盛赎回优先股（支付55亿美元），优先股部分利润约18亿美元。行权后获得超过20亿美元额外利润。合计约38亿美元总收益。 |
| **同步操作** | 2011年8月，同样以50亿美元买入美国银行优先股，年息6%（每年3亿美元），同时获得以7.14美元/股认购7亿股普通股的权证。到2017年，这笔投资已产生约120亿美元利润（不含优先股股息）。 |
| **决策逻辑（推断）** | （1）逆向投资——"在别人恐惧时贪婪"的教科书操作。市场恐慌时优质公司的可转债/优先股提供了极度优惠的条款。（2）巴菲特的品牌效应——他投资高盛本身就向市场传递了信心信号，这也是高盛愿意接受苛刻条款的原因之一。（3）下行保护——优先股+高股息+溢价赎回条款确保了即使股价不涨，伯克希尔也稳赚不赔。 |
| **来源** | Wikipedia: Berkshire Hathaway — 可信度: High |

## 五、后悔的事

### 5.1 没买Google、Amazon、Microsoft

| 维度 | 内容 |
|------|------|
| **事实** | 巴菲特在1994年没有投资亚马逊（当时还在亏损），长期回避Google、Microsoft等科技公司。伯克希尔直到2019年才买入亚马逊股票，且很可能是投资副手的决策。 |
| **巴菲特的具体表态** | 他反复说自己"不理解这些公司"所以不投。关于Amazon，他说自己"无法预测公司的未来增长，而且它在亏损"。关于Google，他承认搜索广告的商业模式非常优秀，但错过了早期投资机会。 |
| **他是否后悔？** | 巴菲特没有明确表达过"深深的后悔"。他的立场是：在自己的能力圈内操作，错过能力圈外的机会不可惜。但考虑到他的长期搭档芒格曾多次公开表示"伯克希尔没有买入Google和Amazon是重大错误"，可以推断巴菲特确实对此有所遗憾。 |
| **关键推论** | （1）巴菲特的"能力圈"原则是一把双刃剑——让他避免了互联网泡沫中的巨大损失（他没买任何科技泡沫股），但也让他错过了科技行业最大的增长机会。（2）2010年代后期他通过Apple间接参与科技领域，说明他确实在尝试调整。（3）与IBM的经验表明，即使他尝试投科技股，也未必能选对标的——这反过来强化了他"留在能力圈内"的信念。 |
| **来源** | Wikipedia: Berkshire Hathaway — 可信度: Medium（对巴菲特内心状态的描述是推断） |

### 5.3 一个关键的模式

从巴菲特的后悔事项中可以识别出一个**重复错误模式**：

1. **情绪驱动决策**（伯克希尔纺织厂）——唯一一次因愤怒而投资，代价最大。
2. **行业判断错误**（ConocoPhillips、航空股2016买入）——对周期性行业的介入，违背了他"远离不可预测行业"的原则。
3. **用股票收购**（Dexter Shoes）——唯一一次用伯克希尔股票支付收购，被证明是代价最高的错误，因为他等于把未来的复利增长送出去了。此后再也没有犯过同样的错误。
4. **卖得太慢**（Tesco）——承认偏差（confirmation bias），当证据变化时行动太慢。
5. **高估护城河**（IBM、卡夫亨氏、Precision Castparts）——对"护城河"的持久性过于乐观，低估了技术变革和竞争格局的变化。

## 六、总结：巴菲特决策框架的关键特征

### 6.1 核心原则（从决策记录中提炼）

1. **能力圈**：只投自己真正理解的企业。在能力圈内他极度自信（机会来临时敢于下重注），圈外他极度自律（宁可不赚也不错）。
2. **逆向操作**：在恐慌中买入优质资产是贯穿其职业生涯的核心模式（1976年GEICO、2008年高盛/美银）。
3. **护城河优先**：品牌忠诚度、定价权、用户转换成本、行业进入壁垒——这些比短期财务指标更重要。
4. **非情绪化（理论上）**：虽然伯克希尔纺织厂是情绪化的反面教材，但这次错误让他建立了终身纪律——投资决策应基于分析，而非情绪。
5. **长期持有**：最成功的投资（可口可乐、美国运通、GEICO）都持有数十年。频繁换手的投资（IBM、航空股）往往失败。

### 6.2 巴菲特的盲点

从这些决策记录中可以识别出几个系统性盲点：

1. **技术范式转换**：他难以评估技术变革对行业结构的影响（IBM被云计算颠覆、报纸被互联网颠覆）。
2. **周期性行业**：他对石油（ConocoPhillips）、航空等强周期性行业的判断多次失误。
3. **管理层误判**：在Tesco、卡夫亨氏等案例中，他对管理层或合作伙伴的判断过于乐观。
4. **规模限制**：伯克希尔的超大规模使其只能进行巨额投资，这限制了可选范围，可能错过许多中型机会。

### 6.3 芒格对巴菲特决策的影响

芒格在以下关键决策中发挥了决定性作用：
- **See's Candies**：说服巴菲特从"烟蒂股"转向"合理价格买优质企业"
- **能力圈扩展**：鼓励巴菲特突破格雷厄姆的纯财务分析框架
- **逆向思维**：持续提供"反过来想"的思考视角

芒格与巴菲特在政治观点上存在分歧（巴菲特更偏民主党/自由派，芒格更保守），但两人在投资决策上高度一致。
